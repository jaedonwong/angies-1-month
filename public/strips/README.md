# Photo strip collections

Add **4 photos per folder**, named `1.jpg` through `4.jpg`.

Then edit captions in `src/data/photoStrips.js`.

## Folders

| Folder | Collection title |
|--------|-------------------|
| `midnight-aurora/` | Midnight Aurora |
| `golden-hour/` | Golden Hour |
| `ocean-breeze/` | Ocean Breeze |

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp` (update paths in `photoStrips.js` if not using `.jpg`).
